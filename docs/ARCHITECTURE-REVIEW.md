## P0 — блокеры (срочно)

### 1. Озвучка букв молчит в веб-сборке
- **Факт**: `verify-voices/VERDICT.md` — в деплое и старые WAV, и новые OGG голоса букв неслышны (RMS ≈ 0.0000 «пыль»), при этом музыка меню громкая (RMS 0.0108–0.1835).
- **Причина**: контент уже проверен (776 файлов громче −35 dB, `_voice_review/`), баг в цепочке воспроизведения/декодирования OGG в WebAudio, не в данных.
- **Действие**: диагностика и починка playback в веб-экспорте.
- **Файлы**: `verify-voices/VERDICT.md`, `azbuka-src/addons/audio_manager.gd`, `azbuka-src/export_presets.cfg` (head_include AudioContext resume hack).

### 2. Физический размер тап-таргетов ниже детской нормы
- **Факт**: база 1080×2340 на 6-дюймовом телефоне ≈ 0.052 мм/px → кнопка высотой 96 px ≈ **5 мм**. Детская норма ≥ **10–12 мм** (взрослая 44pt/48dp ≈ 9 мм; дети 7–10 лет мажут 7 мм в ~30% случаев — Anthony et al. 2013/2019).
- **Действие**: поднять `custom_minimum_size`/реальные размеры интерактивных элементов (кнопки игр 96 px, ответы гейта 200×96, donate 96, back 130×95) так, чтобы **меньшая сторона** каждого тап-таргета была ≥ **190 px** на базе 1080×2340.
- **Норма**: для детей 3–7 лет итоговый физический таргет ≥ 10–12 мм. Численно: 0.052 мм/px → 10 мм ≈ 192 px, 12 мм ≈ 231 px. Таргет **≥ 190 px** (≈ 9.9 мм) принят как нижняя граница; **≥ 200 px** — для запаса. Старые 96 px-таргеты (≈ 5 мм) невалидны.
- **Статус**: реализовано (Vikunja #18, фаза 2). Все интерактивные тап-таргеты подняты до ≥ 190 px. Документированные исключения: пул букв collect_word ≥ 170 px (15 букв «Ёлочная игрушка» не влезают в 900 px рабочей области при 190 px слотах); квадраты слова letter_card для слов из 10+ букв (Электричка, Объявление, Ёлочная игрушка) остаются 190 px и выходят за край экрана — редкие слова, осознанный компромисс.

### 3. Артефакты внутри исходников
- `azbuka-src/build/web/` — 70 МБ веб-экспорт внутри исходной папки.
- `azbuka-src/_audio_legacy_archive/` — 6.4 МБ legacy-аудио (.gdignore).
- `azbuka-src/assets/images/sprites/kisa_anim_test.gd` — тестовый скрипт в папке ассетов.
- **Действие**: вынести за пределы `azbuka-src/` (экспорт в корень репо, как уже сделано для `index.wasm`/`index.pck`), архивы — в `dev/` или git-lfs.

## P1 — рефакторинг (сохраняющий поведение)

### 4. God-класс `letter_card.gd` (894 строки)
- **Факт**: один скрипт владеет UI + рекордером (AudioEffectCapture, 10 с, строки ~92–348) + WAV-энкодером и DSP-нормализацией (~268–340, 618–647) + мини-игрой (~454–683) + темингом + навигацией.
- **Действие**: вынести `VoiceRecorder` (автолоад) и `WordMiniGame` в отдельные скрипты/сцены.
- **Файл**: `azbuka-src/ui/games/azbuka/letter_card.gd`.

### 5. Нет базового класса игры — ~600 строк дублей
- **Факт**: 4 игры (letter_card, find_letter, collect_word, guess_picture) копируют один каркас:
  - idle-хит-таймер 6 с: `_setup/_reset/_stop_idle_timer` ×4 (letter_card.gd:188–216, find_letter.gd:470–499, collect_word.gd:433–461, guess_picture.gd:321–349);
  - 300 Hz бип ошибки (ручной синтез синуса): ×4 (в т.ч. letter_card.gd:618–647, find_letter.gd:554–574);
  - `_image_path_for` ×3 (letter_card.gd:443, find_letter.gd:307, collect_word.gd:377);
  - `_style_nav_button` ~48 строк ×2 (letter_card.gd:817–863, find_letter.gd:504–550);
  - анимации correct/wrong ×2 (letter_card.gd:658–683, find_letter.gd:260–286);
  - `_make_placeholder_texture` ×2.
- **Действие**: ввести `GameScreen` (базовый класс) или `ui/common/game_utils.gd`, вынести общий каркас; дубли заменить наследованием/композицией.

### 6. Центральный реестр навигации
- **Факт**: путь `res://ui/main_menu/main_menu.tscn` размазан: константа `MAIN_MENU_SCENE` ×5 (main_menu.gd:27, azbuka.gd:8, letter_card.gd:13, find_letter.gd:38, collect_word.gd:14) + строковые литералы в settings.gd:304,312,321, guess_picture.gd:245,255. Реестр игр продублирован 3×: `GAME_SCENES`/`GAME_TITLES` (main_menu.gd:11–24), `MODE_KEYS`/`MODE_TITLES` (settings.gd:15–22), `DEFAULT_MODES` (progress_manager.gd:11–16).
- **Действие**: единый `ui/navigation.gd` (или screens.json) — сцены, названия, дефолтные режимы; убить статический mutable-навигатор (`LetterCard.from_letter`, `DonateOverlay.return_scene`, `FeedbackScreen.return_scene`).

### 7. Двойной источник правды по картинкам слов
- **Факт**: `LetterCard.WORD_IMAGE` (letter_card.gd:42–76, 33 записи) + legacy-shim `AlphabetData.get_letter_data()` (alphabet_data.gd:61–78) «для старых потребителей».
- **Действие**: перенести в `content/alphabet_data.json`, выпилить fallback и shim; потребители: find_letter.gd:310, collect_word.gd:380, tests/validate_find_letter.gd:67.

## Steam — чек-лист подготовки

### Графика (размеры после обновления Valve 2024)
Header 920×430, Small 462×174, Main 1232×706, Vertical 748×896, Library Capsule 600×900, Library Hero 3840×1240 (без текста!), Library Logo 1280×720 (прозрачный), Library Header 920×430. Скриншоты: ≥5 шт 1920×1080 только геймплей. Трейлер: H.264+AAC, 16:9, ≤1920×1080, ≥5000 Kbps.

### Техника
- SteamPipe: AppID → launch options на каждую ОС → depots → ContentBuilder VDF.
- Интеграция: GodotSteam (GDExtension) или Godot-Foundation-for-Steamworks (Heathen). GDExtension → обычные шаблоны Godot. В депо: `godotsteam.*` + `steam_api64.dll`/`libsteam_api.so`.
- `Steam.run_callbacks()` каждый кадр; `steam_appid.txt` не включать в релиз.
- Достижения/облако опционально (Steam Cloud рекомендуются для Deck).

### Бизнес/право
- $100 за приложение (возвращается после $1000 выручки); банк + налоговое интервью.
- Content Survey обязателен до ревью; Германия (с 15.11.2024) и Индонезия — без рейтинга игра скрыта в этих странах.
- Цены: 37 валют + 4 региона; незаданная валюта = регион без продаж.
- Детская специфика: Steam SSA — аккаунт с 13 лет → играть будут под родительским аккаунтом; нужна своя privacy policy. Микроплатежи (если будут) — только Steam Wallet.

### Таймлайн (закладывать 3–4 недели)
Ревью страницы 3–5 раб. дней (за 7 дней) → Coming Soon ≥ 2 недели → ревью билда 3–5 дней → ручной «Release App».

### Главные риски отклонения
1. Игра не запускается на заявленной ОС (macOS — нотаризация/exec-флаг).
2. Заявленные фичи отсутствуют в билде.
3. Скриншоты не геймплей / капсула без логотипа.
4. Внешние ссылки в описании.
