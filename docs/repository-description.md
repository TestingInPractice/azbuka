# Репозиторий «Азбука»: описание приложения

## 1. Обзор

«Азбука»: детская развивающая игра для изучения русского алфавита, созданная на Godot 4. Игра упакована как PWA (прогрессивное веб-приложение). PWA является основным каналом распространения, хостинг выполняется на GitHub Pages.

URL приложения: https://testinginpractice.github.io/azbuka/

Приложение рассчитано на детей, которые начинают изучать русский алфавит: 33 буквы, для каждой буквы подобраны слово, картинка, озвучка и игровые задания. Игра работает в браузере на компьютере и на телефоне, включая запись голоса ребёнка через микрофон.

В состав приложения входят:

- общий экран выбора игр;
- четыре игры: «Азбука» (карта-змейка), «Найди букву», «Собери слово», «Угадай картинку»;
- карточка буквы с озвучкой и записью голоса;
- экран настроек (выбор игр, тема, сброс прогресса);
- попап доната;
- экран обратной связи.

## 2. Технологии и платформа

- Движок: Godot 4, язык GDScript со статической типизацией.
- Дизайн-разрешение: 1080x1920 (портрет), режим растяжения canvas_items, aspect expand.
- Экспорт в Web: index.html, index.js, index.wasm, index.pck.
- PWA-компоненты: index.manifest.json (манифест), index.service.worker.js (service worker), index.offline.html (офлайн-страница), набор иконок приложения.
- Хостинг: GitHub Pages (подробнее в разделе «Репозиторий и деплой»).
- Микрофон: запись голоса ребёнка, в конфигурацию проекта добавлено разрешение Microphone для iOS.
- Хранение записей: записи микрофона хранятся локально в директории приложения; для PWA на телефоне используется IndexedDB / локальное хранилище.

## 3. Общий экран выбора игр

Главный экран приложения: экран выбора игр. На нём ребёнок выбирает, во что играть:

- «Азбука»: изучение алфавита;
- «Найди букву»: поиск буквы по звуку;
- «Собери слово»: сборка слова из букв;
- «Угадай картинку»: угадывание слова по картинке.

Помимо кнопок четырёх игр на экране доступны:

- карта-змейка (прогресс изучения букв);
- кнопка настроек;
- счётчик прогресса (например «Прогресс: 0 / 33»).

## 4. Экран настроек

Экран настроек позволяет управлять режимами игры и состоянием приложения:

- выбор списка игр (чекбоксы режимов). Должен оставаться включённым минимум 1 режим: нельзя выключить последний режим игры. При попытке это сделать показывается предупреждение «Должен быть включён хотя бы 1 режим игры»;
- сброс прогресса: кнопка открывает диалог подтверждения («Сбросить весь прогресс по азбуке?»), подтверждение очищает прогресс изучения букв на карте-змейке, кнопка «Отмена» закрывает диалог без изменений;
- переключение темы: светлая и тёмная тема;
- кнопка «Назад» для возврата в меню.

## 5. Попап доната

Всплывающее окно пополнения доната. Предполагается оплата через СБП и ЮMoney.

В текущем коде попап реализован как заглушка DonateOverlay (screens/start_screen/donate_overlay.tscn и donate_overlay.gd). Полноценная интеграция платёжных методов выполняется в отдельной фазе разработки.

## 6. Экран обратной связи

Экран обратной связи собирает отзывы пользователей. Данные отправляются через форму на базе Google Sheets.

## 7. Игра «Азбука» (карта-змейка)

Первая игра «Азбука» представлена экраном-змейкой: буквы алфавита выстроены в виде дорожки-змейки. Каждая буква на дорожке оформлена как круглая кнопка.

Как работает игра:

- при нажатии на букву персонаж Киса бежит от начала дорожки до нажатой буквы;
- открывается карточка выбранной буквы;
- кнопка «Назад» на карточке возвращает на змейку; Киса появляется у последней буквы, состояние запоминается;
- если ребёнок верно ответил на букву в карточке, буква на змейке становится жёлтой;
- прогресс изученных букв сбрасывается в настройках.

## 8. Карточка буквы

Карточка буквы: основной обучающий экран. Ниже приведено схематичное расположение элементов (не в масштабе).

```
+----------------------------------------------+
| [<- назад]                                   |
|                                              |
|                    Аа                         |
|              [картинка: Автобус]              |
|            [А][в][т][о][б][у][с]             |
|                                              |
|        (подсказки и ответы только здесь)      |
|                                              |
|            [<]            [>]                |
|                                              |

 |  [Буква]                             [микрофон]
 [Слово]                              [запись]  |
|                                              |
|       (полоса уровня звука микрофона)        |
+----------------------------------------------+
```

Описание элементов по порядку:

- слева вверху кнопка «Назад»: возврат на змейку (в игре «Азбука») или к списку карточек;
- по центру сверху вниз:
  - буква (например «Аа»);
  - картинка (например «Автобус»);
  - слово по буквам: каждая буква слова расположена в отдельном кликабельном квадратике-кнопке.

Логика клика по букве слова:

- если ребёнок нажал правильную букву (соответствует текущей карточке), голос произносит «Молодец!» (звук prompt_correct.wav, фраза из VOICES.md);
- если буква неверная, звучит звук ошибки, квадратик подсвечивается красным и показывается подсказка «Попробуй ещё!».

Все надписи (подсказки, отчёты о правильности ответа) располагаются в одном месте: под словом-квадратиками. Других мест для текстов на экране нет.

Запись голоса:

- после успешно угаданной буквы голос произносит «Назови всё слово»;
- включается микрофон, запись длится 10 секунд;
- в самом низу экрана отображается полоса уровня звука микрофона (визуализация того, что микрофон работает);
- записи микрофона хранятся локально в директории приложения, что работает даже для PWA на телефоне (IndexedDB / локальное хранилище).

Кнопки управления звуком:

- слева внизу две кнопки: воспроизведение названия буквы и воспроизведение всего слова;
- справа две кнопки: микрофон (запись) и воспроизведение записанного.

Перелистывание:

- по центру экрана кнопки «влево» и «вправо»: перелистывание карточек букв без выхода на змейку.

## 9. Анимация персонажа Киса

Персонаж Киса: кот, сопровождающий ребёнка по карте-змейке. Для персонажа отдельно реализуется анимация движения. Обязательные элементы анимации:

- движение лап при беге;
- движение хвоста.

## 10. Игра «Найди букву»

Вторая игра «Найди букву» учит соотносить звук буквы с её начертанием.

Как работает игра:

- при входе в игру открывается экран «Готовы играть?»;
- по нажатию кнопки открывается карточка случайной буквы;
- в центре карточки расположен граммофон; по нажатию на него воспроизводится звук (например «буква г»);
- ниже расположены 4 больших квадрата с буквами: 3 случайные буквы и 1 правильная, соответствующая звуковой записи;
- слева вверху кнопка «Назад»;
- по центру экрана кнопки «влево» и «вправо»: пролистывание карточек (аналогично игре «Азбука»).

Завершение серии:

- после N карточек показывается экран «Вы прошли все карточки. Начать заново?»;
- «Да»: начинается новая серия из N карточек;
- «Нет»: выход на общий экран выбора игр.

Количество карточек N настраивается в настройках приложения, диапазон значений от 5 до 30.

## 11. Игра «Собери слово»

Третья игра «Собери слово» учит собирать слово из отдельных букв.

Как работает игра:

- в центре экрана слово по буквам со звуковым прочтением;
- ниже: квадраты с перемешанными буквами;
- буквы работают как кнопки: по нажатию буква встаёт на своё место и слово собирается (пример: ч-а-й);
- стрелки «влево» и «вправо» показывают случайные слова;
- кнопка «Назад» слева вверху.

## 12. Игра «Угадай картинку»

Четвёртая игра «Угадай картинку» проверяет знание букв и слов. Описание ниже составлено по текущей реализации (scenes/game_guess_picture.tscn, scripts/game_guess_picture.gd).

Как работает игра:

- игра состоит из 10 раундов (TOTAL_ROUNDS = 10);
- сверху отображается заголовок «Раунд {n} / {n}» и счёт «Счёт: {n}»;
- в центре показывается буква, к которой нужно подобрать слово;
- ниже расположены 4 большие кнопки с вариантами ответа: 3 случайных слова и 1 правильное;
- при правильном ответе звучит «Молодец!», кнопка подсвечивается зелёным, воспроизводится звук буквы, счёт увеличивается на 1, и игра переходит к следующему раунду;
- при неправильном ответе кнопка подсвечивается красным и блокируется, показывается «Попробуй ещё!»;
- после 10 раундов наступает финал: «Игра окончена!», итоговый счёт «Ваш счёт: {n} / {n}», кнопки «Играть ещё» и «Назад».

Примечание: детали игрового цикла этой игры могут быть уточнены в ходе дальнейшей разработки.

## 13. Требования к агент-дружелюбности приложения

Обязательный раздел. Приложение проектируется так, чтобы с ним мог работать агент (ИИ-ассистент) без участия человека. В текущей версии репозитория агенту работать невозможно: не парсится экран, не видны логи, ничего нельзя исправить. Эти требования закладываются в архитектуру с самого начала.

### 13.1. Агент должен уметь парсить экран

- читаемая иерархия узлов и сцен: осмысленные имена узлов (LetterButton, BackButton, а не Node2, Node3);
- стабильные имена узлов и уникальные пути к элементам UI (data-атрибуты / уникальные node paths), которые не меняются между версиями;
- доступность: accessibility-метки, аналогичные aria в веб-приложениях, в Godot Web-экспорте, чтобы агент получал структуру интерфейса из веб-версии;
- каждый интерактивный элемент доступен по стабильному селектору.

### 13.2. Агент должен видеть логи

- структурированное логирование через существующий autoload GameLogger (autoload/logger.gd);
- вывод логов в консоль и в окно отладки;
- экспорт логов в веб-консоль браузера и на сервер, чтобы отлаживать приложение на телефоне;
- единый формат записей (модуль logging/: log_entry.gd, log_level.gd, обработчики console_handler.gd и file_handler.gd).

### 13.3. Агент должен уметь исправлять

- код организован по фичам: папки scenes/, screens/games/*, scripts/, autoload/;
- каждая фича изолирована, связи между фичами сведены к минимуму;
- статическая типизация GDScript (типы у переменных, методов и сигналов), чтобы ошибки ловились до запуска игры;
- разделение на слои: данные (autoload), игровая логика (scripts), представление (scenes/ и screens/).

## 14. Текущая структура проекта

Godot-проект (project.godot) с экспортом в Web. Ниже приведено дерево res:// (основные папки и файлы).

```
res://
├── addons/                       # плагины (зарезервировано, пока пусто)
├── autoload/                     # глобальные синглтоны
│   ├── audio_manager.gd          # звуки (AudioManager)
│   ├── progress_manager.gd       # прогресс (ProgressManager)
│   ├── theme_manager.gd          # темы (ThemeManager)
│   ├── alphabet_data.gd          # данные алфавита: 33 буквы и слова (AlphabetData)
│   ├── global.gd                 # переходы между экранами (Global)
│   └── logger.gd                 # логирование (GameLogger)
├── assets/
│   ├── audio/                    # озвучка: {буква}_letter.wav, {слово}.wav, подсказки и фразы
│   ├── fonts/                    # шрифты
│   └── images/                   # изображения букв и слов
├── components/                   # переиспользуемые компоненты (forest_background)
├── core/                         # низкоуровневые утилиты (core/audio, core/fx)
├── debug/                        # отладочные материалы (пока пусто)
├── logging/                      # система логирования
│   ├── logger.gd
│   ├── log_entry.gd
│   ├── log_level.gd
│   └── handlers/                 # console_handler.gd, file_handler.gd, log_handler.gd
├── scenes/                       # сцены экранов
│   ├── main_menu.tscn            # главное меню
│   ├── start_screen.tscn         # стартовый экран
│   ├── settings_screen.tscn      # настройки
│   ├── roadmap_screen.tscn       # карта-змейка
│   ├── letter_detail.tscn        # карточка буквы
│   ├── letter_card.tscn          # карточка буквы (вариант)
│   ├── game_find_letter.tscn     # игра «Найди букву»
│   ├── game_collect_word.tscn    # игра «Собери слово»
│   ├── game_guess_picture.tscn   # игра «Угадай картинку»
│   └── forest_background*.tscn   # фоновые сцены леса
├── screens/                      # скрипты и сцены по экранам
│   ├── start_screen/             # стартовый экран, donate_overlay
│   ├── settings/
│   ├── roadmap/
│   ├── letter_detail/
│   └── games/                    # find_letter, collect_word, guess_picture
├── scripts/                      # игровая логика по экранам и компонентам
└── docs/                         # документация проекта
```

Дополнительно в корне проекта находятся:

- project.godot: конфигурация проекта и autoload-менеджеры;
- export_presets.cfg: пресеты экспорта;
- index.*: файлы веб-экспорта (index.html, index.js, index.wasm, index.pck, манифест, service worker);
- VOICES.md: полный список фраз, букв и слов с озвучкой;
- PLAN.md: план разработки;
- AGENTS.md: правила работы с репозиторием;
- generate_audio.sh, generate_images*.py: скрипты генерации аудио и изображений.
