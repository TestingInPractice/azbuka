# STANDARDS-GAP: Нормы обучения грамоте (РФ 🇷🇺 + США 🇺🇸) vs «Азбука»

> Исследование проведено 2026-09-23. Первоисточники: ФОП ДО (приказ Минпросвещения №1028), СанПиН 2.4.3648-20, Common Core RF.K, Head Start ELOF, Texas PK3 2022, DIBELS 8, NRP, IRA/NAEYC 1998, NELP 2008.
> Связанные задачи Vikunja (проект #4): метки P0/P1/P2 по этому документу.

## 1. РФ 🇷🇺 — обучение грамоте по возрастам (ФОП ДО)

**Ключевой факт**: официальное знакомство с буквами и слоговое чтение — **только с 6 лет (подготовительная группа)**. До этого — звуковой анализ без букв. Терминология: буквы ≠ звуки, обязательно учить «гласный/согласный», «твёрдый/мягкий».

| Возраст | «Подготовка к обучению грамоте» (ФОП ДО, секции «Подготовка детей к обучению грамоте») |
|---|---|
| **3–4 года** | «Вслушиваться в звучание слова»; термины **«слово», «звук»** в практическом плане (стр. 3133/3214 текста ФОП) |
| **4–5 лет** | Слова состоят из звуков, звучат по-разному/сходно, идут в последовательности, бывают короткими/длинными; различать на слух **твёрдые/мягкие согласные** (без терминов); **первый звук в слове**; слова с заданным звуком; протяжное произнесение заданного звука (стр. 3266/3352) |
| **5–6 лет** | **Звуковой анализ слова**: гласные/согласные, твёрдость/мягкость, ударный/безударный гласный, схемы звукового состава; **деление на слоги** двух-трёхслоговых слов; словесный состав предложения; предложения по живой модели; термины «слово», «звук», **«буква»**, «предложение» (стр. 3419/3515) |
| **6–7 лет** | **Знакомство с буквами; чтение слогов, слов, простых предложений из 2–3 слов**; звуковой анализ **4–5-звуковых слов**; ударный гласный; графические диктанты; членение предложений из 2–4 слов; составление слов из слогов (стр. 3566/3652) |

**Целевой ориентир на выходе из сада** (стр. 1199–1200): «демонстрирует сформированные **предпосылки к учебной деятельности** и элементы готовности к школьному обучению» — без требования «уметь читать». Прямого запрета на раннее чтение в ФОП нет, но структура сама задаёт: буквы = 6+.

### СанПиН 2.4.3648-20 (экранное время, п. 2.10.2)
- ⚠️ **«Занятия с использованием ЭСО в возрастных группах до 5 лет не проводятся»**
- Для 5–7 лет: непрерывный экран **не более 5–7 минут**
- Минимальная диагональ планшета — **26,6 см**; зрительная дистанция — **не менее 50 см**
- Гимнастика для глаз + физкультминутки при использовании ЭСО

> Норматив адресован образовательным организациям, но отражает официальную позицию Минздрава. Для маркировки «0+» и доверия родителей в РФ это аргумент за дизайн коротких сессий (5–7 мин).

## 2. США 🇺🇸 — базовое чтение в детском саду (K) и preschool

| Стандарт | Требование |
|---|---|
| **Common Core RF.K.1.d** | «Recognize and name **all upper- and lowercase letters**» — все 26 букв, оба регистра |
| **RF.K.2.a–e** | рифмы, слоги, **слияние/сегментация onset-rime**, изоляция начального/срединного/конечного звука в CVC-словах, замена звуков |
| **RF.K.3.a–b** | **звуко-буквенные соответствия** (primary sound каждого согласного; долгие/краткие гласные) |
| **RF.K.3.c** | высокочастотные слова наизусть (the, of, to…) |
| **Head Start ELOF (к 5 годам)** | «recognizes and names at least half of the letters» (~13+ букв); начальный звук собственного имени |
| **Texas 2022 PKG (к 4 годам!)** | **20 букв назвать + 20 звуко-буквенных соответствий распознать + 20 произвести** |
| **DIBELS LNF (конец K)** | **~40+ букв/мин** (BOY 25+, MOY 37+, EOY 42+); PSF ~50 фонем/мин; CLS ~35–50 |
| **NRP-лестница фонематики** | изоляция → тождество → категоризация → слияние → сегментация → удаление |
| **IRA/NAEYC 1998** | ПРОПИСНЫЕ → строчные → звуки; по несколько букв за раз; фонематика только ПОСЛЕ части букв |

**Наука (NELP 2008, эффект размеры)**: фонематика сама по себе ES=0.04, + буквы = 0.37, + фоника = 0.57 → **учить звуки строго с буквами**. Трассировка пальцем g≈0.48. Награды вредят (Deci 1999: engagement d=-0.40, completion -0.36, performance -0.28); позитивная обратная связь помогает (d=+0.33).

## 4. Гэп-задачи → Vikunja (метки P0/P1/P2)

Приоритеты Vikunja: P0 → 4 (срочно), P1 → 3 (высокий), P2 → 2 (средний) — конвенция как в задачах #17–#27.

### P0 (блокеры соответствия нормам 4–6 лет)
1. **P0-4: Звуковой анализ слов** — режим «выдели первый звук», «сколько звуков в слове», схемы звукового состава [ФОП 4–6, CCSS RF.K.2]
2. **P0-5: Произношение звуков, а не только названий букв** — озвучка «а», «б» + «А», «Бэ» [ФОП 5–6, RF.K.3.a]
3. **P0-6: Твёрдость/мягкость согласных + гласные/согласные как термины** [ФОП 5–6]
4. **P0-7: Ударный гласный** [ФОП 6–7]

### P1 (нормы старшей группы / подготовка к школе)
5. **P1-8: Лестница рифмы → слоги → первый звук → слияние → сегментация** [NRP + ФОП]
6. **P1-9: Прописные + строчные буквы** [RF.K.1.d, ФОП 6–7]
7. **P1-10: Таймер сессии 5–7 мин + гимнастика для глаз** [СанПиН 2.4.3648-20]
8. **P1-11: Персонализация «буквы из имени ребёнка»** [ELOF, NY PKF]
9. **P1-12: Режим «подготовка к школе» 6–7 лет: чтение слогов и простых слов** [ФОП 6–7]

### P2 (позиционирование и рынок)
10. **P2-13: Английский учебный режим: CVC, sight words, long/short vowels** [CCSS RF.K.2–3] — отдельная сущность из-за фонетики
11. **P2-14: Скорость узнавания букв / прогресс-бенчмарки (DIBELS-стиль)** для родительского дашборда [DIBELS]
12. **P2-15: Документация норм + конкурентный анализ в репозиторий** (этот файл + COMPETITORS.md)

## 5. Выводы для Steam-позиционирования

1. **Нормы РФ и США не конфликтуют, но расходятся в последовательности**: РФ — звуковой анализ с 5, буквы с 6; США — буквы и звуки параллельно с 4–5, флюентность к 6. → **Нужны два режима прогрессии** (русский + английский), а не один.
2. Доказательная база: фонематика **с** буквами (не изолированно), трассировка пальцем, НЕ награды, позитивная обратная связь, сессии 5–15 мин.
3. СанПиН «до 5 лет ЭСО не проводятся» — для Steam-релиза ок (домашнее использование), но в РФ-маркетинге нельзя писать «обучаем чтению с 3 лет». Позиционирование: «развитие фонематического слуха в игре» (3–5 лет), «подготовка к школе» (6+, буквы и слоги).
4. Русская специфика — уникальные механики: твёрдость/мягкость, ударный гласный, йотированные гласные, схемы слов. Этого нет ни у одного англоязычного конкурента → дифференциатор для РФ.
5. Английский режим — **отдельный контент** (CVC, sight words, long/short vowels), а не перевод: фонетика русского и английского не совпадает.
