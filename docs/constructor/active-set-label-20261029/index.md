# Подпись активного набора в игре

Дата: 2026-10-29
Ветка: feat/active-set-label
База: azbuka-v2, 6e8601c

## Зачем

Тестовый набор собран из встроенного набора 1, слова и картинки там те же. На
экране «Азбука» нет ничего, что говорило бы, какой набор активен, поэтому
родитель выбирает «Тестовый набор», открывает букву А, видит «Авто́бус» и
решает, что выбор не применился. Выбор при этом применялся: в логах
`custom_set_changed {"set_id":"c_51ba5d"}`, в `progress.json`
`"word_set_id":"c_51ba5d"`, карточка читала файлы из `custom_sets/c_51ba5d/`.

## Что добавлено

- `systems/set_repository.gd`: `get_active_set_name()` возвращает имя активного
  пользовательского набора либо пустую строку для встроенного, удалённого и
  отсутствующего набора.
- `ui/games/azbuka/azbuka.tscn` и `azbuka.gd`: подпись `Набор: <имя>` под
  заголовком. Для встроенных наборов узел скрыт и не занимает места в VBox,
  поэтому змейка выглядит как раньше.
- `ui/games/azbuka/letter_card.tscn` и `letter_card.gd`: та же подпись внизу
  карточки, между колонками кнопок. Обновляется при каждой смене буквы, так что
  переименование набора видно без перезапуска.

Цвета подписи берутся из темы: на «Азбуке» `ThemeManager.get_text()`, на
карточке белый текст с тёмной обводкой, как у подсказки поверх картинки.

## Геометрия (1080x2340, тестовый набор)

| Элемент | Rect |
|---|---|
| Азбука, SetLabel | ширина 460, по центру, между заголовком и змейкой |
| Карточка, SetLabel | `x 230..850`, `y 2030..2114` |
| Карточка, кнопки «Буква»/«Слово» | `x 30..230` |
| Карточка, кнопки «Микрофон»/«Слушать» | `x 850..1050` |
| Подсказка «Найди букву» | `y 1926..2023` |

Подпись стоит в свободной полосе между колонками кнопок и не пересекается ни с
ними, ни с подсказкой.

## Что проверено

Новый валидатор `tests/validate_active_set_label.tscn`: 44 проверки, все
проходят. Покрытие: встроенные наборы 1..5 без имени и без подписи; свой набор
даёт имя и видимую подпись с точным текстом `Набор: Тестовый набор`;
переименование меняет текст; удалённый набор скрывает подпись; повторное
открытие сцен не оставляет лишних узлов; переключение темы сохраняет
читаемость; длинное имя переносится по словам и не ломает змейку (33 кружка,
положительная высота области).

Полный прогон всех 16 сцен валидаторов в изолированной копии: PASSED. Логи в
`suite/`.

## Ограничения

- Подпись показывает имя набора, а не его содержимое: у тестового набора слова
  по-прежнему совпадают с набором 1, это осознанно.
- Другие игры («Найди букву», «Собери слово», «Угадай букву») подпись пока не
  показывают.
- Переполнение очень длинного имени на реальном телефоне проверено только
  расчётом геометрии и автопереносом, не глазами на устройстве.
